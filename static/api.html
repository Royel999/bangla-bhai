Bangla Bhai API (session cookie)

All /bb/api/* routes require a logged-in session (email OTP or owner password).

Auth

POST /auth/otp/request   form: email
POST /auth/otp/verify    form: email, code
POST /login              form: username, password  (owner)
GET  /bb/api/me

Chat

GET/POST /bb/api/chats
GET/PATCH/DELETE /bb/api/chats/{id}
POST /bb/api/chats/{id}/stream   JSON {content, model, council}
POST /bb/api/intent              JSON {text} → {action, device_hint}
POST /bb/api/agent               JSON {goal} → {id}
GET  /bb/api/agent/{id}?since=n
POST /bb/api/agent/{id}/decide   JSON {id, ok}

Settings / devices

GET/PUT /bb/api/settings
GET  /bb/api/devices
POST /bb/api/devices/{id}/approve|deny|perm|remove
POST /bb/api/tts  POST /bb/api/stt  POST /bb/api/upload

Agent tools & permission caps: see PLAN.md and /bb/link/README.md
