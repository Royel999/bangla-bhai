The Royal Bengal Tiger — Android অ্যাপ ইনস্টল

অ্যাপে Accessibility (স্ক্রিন পড়া/ট্যাপ) আছে। তাই ব্রাউজার বা ফাইল ম্যানেজার থেকে ইনস্টল করলে Google Play Protect অনেক দেশে আটকে দেয়। এটা অ্যাপের ত্রুটি নয়, Google-এর নিরাপত্তা নিয়ম। অ্যাপে SMS পারমিশন নেই।

পথ ১ — ফোন থেকেই (আগে এটা চেষ্টা করুন)

  1. পুরনো Royal Link ও বাংলা ভাই থাকলে আনইনস্টল করুন।
  2. RoyalBengalTiger.apk ডাউনলোড করুন।
  3. Play Protect এলে More details → Install anyway।
  4. অ্যাপ খুলে লগইন → সবুজ বার থেকে Accessibility চালু (Android ১৩+ এ আগে App info → ⋮ → Allow restricted settings)।

পথ ২ — কম্পিউটার দিয়ে ADB (পথ ১ আটকালে)

  1. ফোনে Settings → About phone → Build number ৭ বার চাপুন → Developer options → USB debugging চালু।
  2. কম্পিউটারে Google-এর ফ্রি Android SDK Platform-Tools নামান (developer.android.com/tools/releases/platform-tools)।
  3. USB দিয়ে ফোন যুক্ত করে ফোনে "Allow USB debugging" দিন।
  4. কমান্ড: adb install -r RoyalBengalTiger.apk
  5. কাজ শেষে USB debugging বন্ধ করে দিন।

সতর্কতা

Android 17-এ Advanced Protection চালু থাকলে Accessibility দেওয়া যায় না। ব্যাংক, OTP ও পাসওয়ার্ডের স্ক্রিন অ্যাপ কখনো পড়ে না; প্রতিটা ট্যাপ/টাইপের আগে আপনার Approve লাগে।
