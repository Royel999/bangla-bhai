# বাংলা ভাই (Bangla Bhai)

A Bangla-first AI assistant and agent: chat in Bangla, English and 6 more languages, voice input with a male Bangla voice reply, photo/PDF reading, a free image Studio with bring-your-own-key paid models, memory, an activity log with approve/deny for risky actions, saved skills, scheduled jobs with push notifications, a Telegram bot, Free/Pro/Business plans (Business includes up to 5 team seats) and an owner admin dashboard.

**Live:** https://banglabhai.dpdns.org

## Run it
- **Windows (one click):** download [`windows/install.bat`](windows/install.bat) and double-click it. See [`windows/GUIDE_BN.md`](windows/GUIDE_BN.md).
- **Linux:** `python3 -m venv venv && venv/bin/pip install -r requirements.txt`, fill in `.env` from `.env.example`, then `./start.sh`.
