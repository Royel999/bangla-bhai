# Bangla Bhai (by Royal Universe)
Multilingual AI assistant (FastAPI, PWA). Default language English; bn, hi, ar, ur, es, fr, zh.

- Windows: double-click `install.bat`, then see **GUIDE_BN.md**.
- Linux: `python3 -m venv venv && venv/bin/pip install -r requirements.txt && cp .env.example .env && ./start.sh`

Config lives in `.env` (never committed). Runs on http://127.0.0.1:8090.
